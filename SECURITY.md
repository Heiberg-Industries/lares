# Security reporting

Lares is under active development. CI results and public source availability are not a security certification.

Please do not open a public issue containing an unpatched vulnerability, exploit instructions, credentials, or personal data. Use GitHub's **Report a vulnerability** option on the repository's Security tab when available. If it is unavailable, ask the maintainer through their GitHub profile for a private reporting channel before sending details.

A useful private report includes the affected commit, a minimal reproduction using synthetic data, the expected boundary, and the observed impact. Remove tokens, customer content, private hostnames, and real account identifiers from attachments.

Security response is best effort. No response-time guarantee or bug bounty is offered. Keep installations private, grant integrations only the access they need, and review updates before deploying them.
