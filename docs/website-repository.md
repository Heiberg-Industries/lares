# Website source boundary

The marketing site and curated public docs at https://lares.is are maintained in
the private `Heiberg-Industries/lares-website` repository. They are not installed
with Lares. Engine, console, installer, self-hosting and contributor documentation
remain in this public repository.

`packages/ui` owns the shared console design tokens and fonts. The website has an
explicit pinned snapshot with hashes and licences; changes are reviewed and synced
there. Historical marketing sources remain in Git history. This move does not
rewrite public history or change existing source licences.
