# Lares public website

This is the production-code marketing shell based on the approved design preview.
It is a separate application from the authenticated console and imports only the
shared presentation tokens from `@lares/ui`.

The current signup fields are disabled because no submission destination has been
approved and verified. This app is not deployed by the self-hosted installer.
The content still needs the brand, availability, legal, docs, contact, booking,
consent and telemetry review recorded under LAR-9 and LAR-11 before publication.
