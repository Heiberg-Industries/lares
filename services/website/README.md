# Lares public website

This is the production-code marketing shell based on the approved design preview.
It is a separate application from the authenticated console and imports only the
shared presentation tokens from `@lares/ui`.

The repository is open, so this site has no waitlist or signup. Its contact
section offers an email link for setup requests and other messages. The booking
link currently opens the existing Heiberg booking page. A Lares-styled popup
needs an Orbis booking brand/frame-policy change first; see
`docs/marketing/analytics-and-launch.md`.

This app is not deployed by the self-hosted installer. The content still needs
brand, availability, legal, docs, contact, booking, consent and telemetry review
under LAR-9 and LAR-11 before publication.
