## Current status

Lares is experimental alpha software. A complete fresh installation followed by a healthy first agent and a provider-backed conversation remains an open release gate. A successful build is not proof of that end-to-end path.

## Before you start

Use a disposable environment for evaluation. You need a server you control, model-provider API access and credentials for any optional integrations. Keep installation secrets out of Git.

The engine repository contains the shared software. Agent definitions, settings and personal data belong to the installation.

## Source and development

The repository documents the current setup constraints and development prerequisites. Use its current instructions rather than treating this overview as a production installation runbook.

[Open the repository](https://github.com/Heiberg-Industries/lares) and [review the tested-install-path decision](https://github.com/Heiberg-Industries/lares/blob/main/docs/decisions/0022-the-tested-install-path.md).
