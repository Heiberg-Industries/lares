The console is the web interface to your Lares installation. It brings agent setup, conversations, connections and operational settings together.

## Agents and conversations

Each agent has a name, purpose and access settings. Create the first agent from the console and check that its runtime is healthy before starting a conversation.

Web chat is the first conversation route. Connecting other channels requires their own setup. The current interface is being refined; screenshots on the marketing page are illustrative examples.

## Review and permissions

Access is configured per agent. Review prompts and permissions determine which actions need your decision. A visual status alone does not prove that an external action was delivered.

## Connections and settings

Connected services and model providers need their own credentials. Keep those credentials on your installation, outside the source repository.

Read [agents and permissions](/docs/agents) or [installation](/docs/installation) next.
