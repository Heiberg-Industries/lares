# Havnelager — warehouse to apartments

Our own speculative project: converting the old Havnelager harbour warehouse
into eight apartments, bought outright rather than for a client. Priya
Nataraj did the permit drawings; Erik Dahl surveyed the structure and
flagged that the south wall needs new steel before the ground floor can be
opened up.

Still waiting on the municipality's zoning response before we commit to a
start date.
