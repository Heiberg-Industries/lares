# Adopt Byggflyt for job tracking

Moved every live job's schedule, budget and photo log into Byggflyt instead
of the shared spreadsheet we'd outgrown. Ingrid owns the setup; every site
lead adds their own daily photo dump so nothing lives only on someone's
phone.
